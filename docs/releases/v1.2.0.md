# SluPlayer 1.2.0

Windows 10·11 64비트용. RTX 업스케일을 추가했습니다.

## 변경 사항

- **RTX 업스케일**: 화면 우클릭 → **RTX 업스케일**로 켜고 끕니다. 화면보다 작은 영상을 NVIDIA RTX Video Super Resolution으로 화면 크기에 맞춰 키웁니다. 따로 설치할 것은 없고, 켜 두면 다음 영상에도 적용됩니다.
  - NVIDIA RTX 그래픽 카드(RTX 20 시리즈 이상)와 최신 드라이버가 필요합니다. 다른 그래픽 카드에서는 메뉴에 표시되지 않습니다.
  - 약 480×360 이상의 SDR 영상에 적용합니다. 화면 크기 이상이거나 HDR인 영상은 원본 그대로 재생합니다.
- **설정·다운로드 창**: 우클릭 메뉴에서 연 설정·다운로드 창이 곧바로 플레이어 뒤로 가려지던 문제를 고쳤습니다.
