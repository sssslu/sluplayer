# SluPlayer 1.1.0

Windows 10·11 64비트용. .NET 런타임이 포함되어 있습니다.

## 변경 사항

- **X 로그인 지원**: 다운로드 창 아래 **X [로그인]**, 설정의 **X 계정**, 또는 실패한 항목의 **[로그인]**에서 로그인할 수 있습니다. 로그인 후 해당 사이트에서 실패한 항목을 다시 시도합니다.
- 로그인한 계정에 접근 권한이 있는 민감한 게시물과 비공개 계정 게시물을 받을 수 있습니다. 비공개 계정은 해당 계정을 팔로우하는 계정으로 로그인해야 합니다.
- YouTube와 X의 로그인 정보와 브라우저 프로필을 별도로 관리하고, X 다운로드 오류 안내를 개선했습니다.
- 영상 시작이 늦어지는 파일에서 오디오 재생을 먼저 시작하도록 개선했습니다.
