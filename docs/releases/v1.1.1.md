# SluPlayer 1.1.1

Windows 10·11 64비트용. X 로그인 지원을 포함한 안정성 업데이트입니다.

## 변경 사항

- **정지**: 파일이나 폴더를 여는 중 정지하면 대기 요청도 취소해, 나중에 재생이 다시 시작되지 않습니다.
- **다운로드 재시도**: 이전 다운로드의 임시 파일 정리가 새 다운로드 파일을 삭제하지 않도록 처리 순서를 보장했습니다. 같은 영상의 정리를 기다리는 동안 다른 다운로드는 계속 진행합니다.
- **MP4·MKV 저장**: 영상과 음성이 이미 합쳐진 원본도 선택한 형식으로 저장합니다. 영상 재인코딩 없이 컨테이너만 바꾸며, 이미 같은 형식이면 추가 변환을 생략합니다.
- **설치·업데이트**: 기존 파일과 임시 복사본이 함께 차지하는 공간까지 계산해 공간 부족을 미리 확인합니다. 파일 교체 중 일시적인 잠금이 발생하면 짧게 재시도합니다.
- **화면 조작**: 스크롤바 빈 곳을 클릭하면 페이지 단위로 이동합니다. 현재 재생 항목을 남기는 목록 정리 버튼은 **다른 항목 지우기**로 표시합니다.
- **접근성·코드 정리**: 계정·파일 연결 상태와 버전의 실제 값을 화면 읽기 도구에 전달하며, 사용하지 않는 내부 코드를 정리했습니다.
