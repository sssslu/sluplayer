2. Source code (GPL components)
-------------------------------

The complete corresponding source code of the GPL-licensed binaries is available at no
charge from the following locations:

  mpv          https://github.com/mpv-player/mpv/tree/e471496c56f0f49c133bd88b50aed62b845f1909
  libmpv build https://github.com/shinchiro/mpv-winbuild-cmake (release 20261021: the build
               recipes list every bundled library and its exact source revision)
  FFmpeg       https://github.com/FFmpeg/FFmpeg/tree/5a54fcf75e
  FFmpeg build https://github.com/yt-dlp/FFmpeg-Builds (tag autobuild-2026-09-30-18-57: build
               scripts and the revisions of all bundled libraries)

If one of these locations becomes unavailable, the distributor of this SluPlayer package
will provide the corresponding source code on request for at least three years, for no
more than the cost of physically performing the source distribution.
